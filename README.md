# Server-TCP-UDP
Nesse projeto, estou aplicando conhecimentos que ganhei através do curso Python para Pentester na udemy.<br>
Como uma forma de prática em cima do aprendizado, decidi montar esse servidor TCP e UDP. Como POO é algo que estou aprendendo também, decidi aplicar.

O termo sockets é um pouco confuso ainda para mim, porém tentarei explicar oque aprendi.
- Primeiro, devemos ter uma noção básica do modelo TCP/IP. O socket funciona na camada de aplicação e transporte, usando protocolos como TCP ou UDP (que é o caso desse programa).
- Socket cria uma conexão lógica entre cliente e servidor (sendo máquinas diferentes ou até mesmo em uma única máquina).
- Sabendo disso podemos perceber que o socket é um canal de comunicação, usando o IP e Porta.
